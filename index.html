🗺️ הגדרות מפות Google

      
    

    

      

        עם מפתח Google — השלמת כתובות תוך כדי הקלדה, זיהוי מיקום מדויק ומהיר, ותצוגות מפה של Google.

        1. Google Cloud Console → Maps Platform — צור מפתח API

        2. הפעל שלושה שירותים: Geocoding API (השלמה + מיקום), Maps Embed API (תצוגה בכרטיס תורם — חינמי), ו-Maps JavaScript API (מפת המסלולים האינטראקטיבית)

        3. מומלץ: הגבל את המפתח לשלושת השירותים האלה + הגדר תקרת שימוש יומית

        ללא מפתח — המערכת ממשיכה עם OpenStreetMap (חינמי, איטי ופחות מדויק).

        💡 לזרז: ניתן להשתמש ב-Google Maps Geocoding API (בתשלום) שמאפשר מאות קריאות לדקה — צור קשר עם מפתח המערכת להפעלה.
